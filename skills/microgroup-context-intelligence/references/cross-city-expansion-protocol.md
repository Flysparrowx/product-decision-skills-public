# Cross-city Expansion Protocol

Use this protocol to find functional analogues of a seed microgroup in other cities or countries.

## 1. Decompose the seed

Classify every DNA element:

- `STABLE CORE`: shared situation, desired progress, central tension, social function, recurring practice, status/trust logic;
- `LOCAL EXPRESSION`: neighborhood, venue, brand, creator, phrase, platform, clothing manifestation, schedule, event format;
- `UNKNOWN`: plausible but not validated as either structural or local.

Do not transfer protected traits, individual identities, literal hashtags, or one city’s demographic shorthand as the definition of the group.

## 2. Build a local query pack

For every stable-core dimension generate locally adapted seeds across:

```text
self-labels and role names
problem and aspiration language
activity, ritual, tool, product, and event terms
venue and neighborhood types
organizers, institutions, creators, and media ecosystems
local spelling, transliteration, dialect, and platform variants
complaints, skeptical language, and negative cases
```

Translate social function rather than words. A Moscow “маркет” may map to a studio sale, pop-up, makers’ fair, flea event, or another locally meaningful format.

## 3. Compare candidates

For each city assess:

| Dimension | Seed | Candidate | Match type | Evidence | Counterevidence |
| --- | --- | --- | --- | --- | --- |
| Shared situation/tension | | | CORE / LOCAL / NONE | | |
| Desired progress | | | | | |
| Practice and ritual | | | | | |
| Communication grammar | | | | | |
| Status and trust | | | | | |
| Place and time rhythm | | | | | |
| Public ecosystem | | | | | |
| Product-relevant constraint | | | | | |

Use the same evidence window and source classes where practical. Do not penalize legitimate local differences as if they were missing values.

## 4. Validate the analogue

Require:

- evidence of the stable core, not only visual similarity;
- at least one local source independent of a global creator or imported trend;
- an adjacent candidate and a negative case;
- explicit platform, language, tourist, event, and researcher bias checks;
- a local member/expert check for `DEEP` work or expensive market-entry decisions.

Return `FUNCTIONAL ANALOGUE`, `ADJACENT SCENE`, `SURFACE LOOKALIKE`, or `INSUFFICIENT EVIDENCE`, with confidence and the cheapest disambiguating test.
